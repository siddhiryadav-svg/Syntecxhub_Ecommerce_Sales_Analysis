
# E-commerce Sales Data Analysis

## Internship
Syntecxhub - Data Science Internship

## Project Objective
To read, inspect, filter and analyse e-commerce sales
data using Python Pandas.

## Dataset Information
- Total Records: 1000
- Dataset Type: Synthetic Data
- File Format: CSV and Excel

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Features
1. CSV and Excel file handling
2. Dataset inspection
3. Statistical analysis
4. Data filtering and sorting
5. Product-wise sales analysis
6. City-wise sales analysis
7. Data visualisation
8. Exporting filtered data

## Data Quality
- Checked missing values
- Checked duplicate records
- Validated product categories
- Validated product prices
- Verified total sales calculations

## Note
The dataset is synthetically generated
for educational and analytical purposes.
